# Security policy

`dist-parity` parses untrusted archives and intentionally never extracts or executes their contents. Do not assume that it makes an archive safe to install or publish.

If you identify a security problem, **do not open a public issue containing exploitation details or secrets**. Contact the repository owner through GitHub private security advisories once the repository is published (Settings → Security → Advisories). If that channel is not configured, ask for a secure disclosure channel without sharing sensitive details.

Supported version: most recent tagged release. Security fixes are prioritized over feature requests.
