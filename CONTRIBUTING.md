# Contributing

Thanks for helping maintain Python packaging quality.

1. Discuss significant behavioral changes in an issue first.
2. Fork, create a focused branch, and write regression tests.
3. Run `python -m unittest discover -s tests -v` (Python 3.11+).
4. Open a PR explaining the artifact scenario, metadata version and expected behavior.

Please use synthetic artifacts or public releases in tests; do not upload private package code or credentials. Maintainers review all contributions before merging.
